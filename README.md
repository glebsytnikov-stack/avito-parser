# 🚀 Авито Парсер - Браузер + Поведение человека + Категории

Полнофункциональный парсер для Авито с браузером Selenium, имитацией поведения человека и специализированными парсерами для разных категорий товаров.

## ✨ Главные возможности

### 🧠 Интеллектуальная имитация поведения
- ✅ **Движение мыши** - случайные движения как у человека
- ✅ **Прокрутка страницы** - плавная прокрутка с остановками
- ✅ **Случайные паузы** - для имитации чтения контента
- ✅ **Реалистичные задержки** - между действиями и запросами
- ✅ **Скрытие автоматизации** - Selenium не обнаруживается

### 🛡️ Обход защиты
- ✅ Ротация User-Agents
- ✅ Поддержка про��си
- ✅ Обработка Rate Limiting (429)
- ✅ Автоматические повторы с backoff
- ✅ Загрузка JavaScript контента

### 📦 Специализированные парсеры
- ✅ **Одежда** - размер, бренд, состояние
- ✅ **Автомобили** - марка, модель, год, пробег
- ✅ **Квартиры** - комнаты, площадь, этаж, адрес
- ✅ **Телефоны** - бренд, модель, память, состояние

### 💾 Экспорт данных
- ✅ SQLite / PostgreSQL БД
- ✅ CSV файлы
- ✅ JSON файлы
- ✅ Встроенный поиск и фильтрация

## 🧠 Как работает имитация поведения

### Браузер-парсер выполняет:

1. **Загрузка страницы** - как обычный пользователь
2. **Прокрутка вниз** - медленная, с остановками (300-1000px за раз)
3. **Паузы для чтения** - 1-3 секунды между действиями
4. **Движение мыши** - случайные движения на странице
5. **Клики** - с перемещением мыши перед кликом
6. **Ожидание контента** - не торопится, ждет загрузки

### Результат:

✅ Авито не блокирует парсер  
✅ Выглядит как реальный пользователь  
✅ Загружается JavaScript контент  
✅ Обходится защита от ботов  

## 🎛️ Параметры CLI

```bash
# category_parser.py
python category_parser.py [категория] [страницы] [--headless/--no-headless]

Категории: clothes, cars, apartments, phones, all
Страницы: 1-10 (количество страниц для парсинга)
--headless: режим без окна браузера (по умолчанию)
--no-headless: показывать окно браузера
```

```bash
# main.py
python main.py URL [опции]

Опции:
  -p, --pages N       Количество страниц (по умолчанию 1)
  --headless          Режим без окна
  --details           Загружать детали каждого объявления
  --csv               Сохранить в CSV
  --json              Сохранить в JSON
  --db                Сохранить в БД (по умолчанию)
  --no-browser        Использовать простой парсер
  -o, --output FILE   Имя выходного файла
```

## 🚨 Важные замечания

1. **Используйте ответственно** - соблюдайте robots.txt Авито
2. **Задержки обязательны** - минимум 2 секунды между запросами
3. **Прокси рекомендуются** - для долгосрочного мониторинга
4. **Селекторы** - если Авито обновится, селекторы нужно актуализировать
5. **Лимиты IP** - не парсьте более 100 страниц в час

## 🐛 Решение проблем

**Браузер не запускается**
```bash
# Установите Chrome
sudo apt-get install chromium-browser  # Linux
# или скачайте с https://www.google.com/chrome/

# Проверьте логи
cat avito_parser.log
```

**Ошибка "element not found"**
- Селекторы сайта изменились
- Обновите селекторы в `parser.py` и `advanced_parser.py`

**Высокое потребление памяти**
- Используйте `--no-browser` для больших объемов
- Парсьте меньше страниц одновременно

**Блокировка по IP**
- Включите прокси в `.env`
- Увеличьте задержки
- Используйте режим headless
